# Практика C# — интерфейсы медицинских справок

Отдельный консольный проект. Все классы и интерфейсы задания находятся в `Program.cs`.

## Запуск

В папке проекта выполните:

```powershell
dotnet run
```

## Что реализовано

1. `ISpravka` задаёт общий контракт для медицинских справок: имя, пациента, цену и методы показа, расчёта цены и краткого описания.
2. `Spravka083`, `SanitaryCard` и `SpravkaBassein` реализуют этот интерфейс. У справки в бассейн есть дополнительное свойство `ValidMonths`; у санитарной книжки учитываются анализы.
3. `GetShortInfo()` добавлен в интерфейс и реализован каждой справкой.
4. `Patient` хранит имя, телефон, email и группу крови.
5. `Kassa.Total()` считает общую стоимость, а `Kassa.PrintCheck()` печатает справки и итог.
6. `INotifier` реализуют SMS, Email и Telegram уведомители. Выбор способа сделан через `switch`.

Уведомления демонстрационные: программа выводит их в консоль и не отправляет сообщения через реальные сервисы. Данные пациента в примере учебные.

Пример чека: справка 083 — 100,00; санитарная книжка с тремя анализами — 750,00; справка в бассейн — 200,00; всего — 1050,00.
